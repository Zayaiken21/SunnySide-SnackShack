# Sunny Side Snack Shack — World Map Sync Production Build

## Major fixes

- Pause button is now inside the border and no longer hangs off the phone screen.
- Hidden decorative emojis behind the conveyor are removed.
- Conveyor belts visibly move and only show foods actually on the tray or saved build.
- Players are compact at the top so 4-player rooms do not hide the game.
- Co-op players share the same synced order and can help each other.
- Versus players get separate orders while seeing each other's scores.
- Vote Map now opens correctly.
- Vote screen has Back Room, Ready, and Leave Room.
- Map voting now spins between the voted maps and randomly lands on one.
- Multiplayer has tutorial vote/skip; match does not start until all players vote.
- Tutorial shows small pointer tips instead of a full-screen takeover.
- Account coins are earned from solo/multiplayer and go toward real upgrades.
- Upgrades now match gameplay: prep, patience, tips, and team counter.
- 100 map levels are now organized as 10 worlds with 10 unique named stops each.
- No duplicate theme names.
- Multiplayer starts at Level 1 on the chosen map.
- Screen boundaries and safe-area behavior improved for iPhone and other devices.

## Deploy

Upload these files to GitHub and Render will redeploy.

Build command:
npm install

Start command:
npm start
